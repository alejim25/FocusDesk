# FocusDesk — Instrucciones para Codex

## Contexto
FocusDesk es un proyecto educativo para aprender desarrollo de software con agentes de IA.
El usuario está aprendiendo programación.

## Reglas del proyecto
- Mantén la aplicación sencilla: HTML, CSS y JavaScript sin frameworks.
- Evita dependencias y funcionalidades innecesarias.
- Antes de cambios importantes, inspecciona el código existente y explica brevemente el enfoque.
- Prioriza cambios pequeños y fáciles de revisar.
- Conserva la persistencia de sesiones en localStorage.
- No hagas commits, push ni merge sin autorización explícita.

## Al terminar una tarea
- Resume qué archivos modificaste y por qué.
- Explica cómo comprobar manualmente el resultado.
- Señala las pruebas que realmente ejecutaste y las que quedaron pendientes.
